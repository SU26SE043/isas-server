# định chất lượng chép lời và nhận diện mặt.
#
# Cách dùng (Dockerfile): `pip install -r requirements.txt -c requirements.lock.txt`.
#   • `requirements.txt` vẫn là nơi KHAI phụ thuộc (thêm gói mới ở đó, không phải ở đây).
#   • File này chỉ CHẶN phiên bản — kể cả phụ thuộc bắc cầu không hề xuất hiện trong
#     requirements.txt (ctranslate2, tokenizers, onnx, scipy, av...).
#   ⚠ ĐỪNG đổi sang `pip install -r requirements.lock.txt`: làm vậy biến requirements.txt thành
#     tài liệu chết — thêm gói vào đó mà quên file này thì image KHÔNG có gói, và lỗi nổ lúc
#     chạy dưới dạng ImportError ở chỗ chẳng liên quan.
#
# Chạy test cục bộ cho khớp image (constraints KHÔNG tự kế thừa qua `-r`):
#   pip install -r requirements-dev.txt -c requirements.lock.txt
#
# Tái sinh (khi cố ý nâng cấp — phải là một quyết định, không phải tác dụng phụ):
#   docker run --rm --entrypoint pip <image> freeze | LC_ALL=C sort > requirements.lock.txt
#   rồi chép lại khối header này lên đầu.
#   ⚠ LC_ALL=C bắt buộc: không có nó thì thứ tự đổi theo locale máy (aio-pika trước/sau aiohttp)
#     và step guard trong CI sẽ báo lệch giả.
#

# và FAIL nếu lệch. Nó bắt đúng ca `-c` không phủ được: một phụ thuộc bắc cầu MỚI xuất hiện
